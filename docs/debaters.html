Checking the debaters

Run on real venture data rooms, LLM debate agents invented the evidence that unlocked INVEST verdicts, and the agent holding the veto accepted it. Putting the documents in every turn and checking every quote in code, with a checker that survives PDF noise, stopped it.

What is new

vs AlphaAgents (Zhao et al., 2025)

Specialist agents debate equity decisions over public data. Here the same pattern runs on private venture data rooms, where the failure that matters is invented evidence: every quote is checked against the documents in code, stated figures enter the deal math only through a verified fact ledger, and the risk veto is gated on verified quotes.

vs Khan et al. (2024)

Their verified-quote tool checks debaters' quotes by exact match against one clean story. Venture data rooms are many noisy PDFs, where exact matching finds 31.5% of real quotes. The checker here tolerates extraction noise and stays strict on figures, names, negations and qualifiers.

vs Irving et al. (2018)

Debate as oversight assumes a judge who knows less than the debaters. Here that judge holds a veto over a real decision, and a controlled replay tests what it needs: document sight, displayed checks, or a gate enforced in code.

vs DIALECTIC (Bae et al., 2026)

The closest system for startups gathers facts into a question tree and ranks deals with debate-refined arguments; it does not describe checking quoted evidence against the source documents. Here every quote and every stated figure is checked in code, and deal arithmetic is computed, not generated.

The system

Six agents score the deal, argue it in two adversarial rounds audited by a referee that cannot see the documents, face the Risk Agent's objections, and vote. Every statement passes through the citation checker before any other agent reads it.

Phase 0Fact ledgerFigures enter only if their quote is found and contains the value; deal math is computed by functions
Phase 1ScorecardsSix agents score the deal independently, every rationale quoted
Phase 2OpeningsPanel first, Risk Agent last, having heard them
Phase 3Cross-examination ×2A document-blind referee names logical fouls and presses for rebuttals
Phase 4Risk gauntletObjections, panel answers, ruling; a gate downgrades any "resolved" without a verified quote
Phase 5VoteRisk veto plus 3 of 5 panel votes to INVEST
On every turn: the full documents in the prompt; every «quote» checked against them in code and annotated (found / NOT FOUND) before the next agent reads it; Quant arithmetic re-computed in code.

What the judge needs: sight or checks, not a gate

Debates in which the Risk Agent resolved an objection without a verified quote, out of 7

The final ruling replayed 252 times on saved debates under one frozen commit (2 models × 6 arms × 3 repeats). Blind and unchecked, the judge copied a panelist's fabricated quotes into its ruling. Either showing it the documents or showing it the check results stopped that; the code-enforced gate changed none of the 252 verdicts.

Judge cannot see the documents Judge sees the documents Before the code gate

A sighted judge quotes the documents directly, so its few misses are its own near-quotes, not copied fabrications.

Scope

  • The checker establishes that quoted words exist in the documents, not that they support the claim; in one run the Risk Agent passed the gate with a real quote that answered a different objection.
  • No investment outcomes yet: DIALECTIC backtests against real outcomes from five funds; this work does not.
  • The data rooms are confidential, so deals appear as D1–D7 and results as counts; the public code runs end to end on a fictional data room.
